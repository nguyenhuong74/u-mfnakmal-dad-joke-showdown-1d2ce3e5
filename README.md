One dad joke, written to be told out loud at the dinner table — a fresh pun with
the punchline landing at the end:

> I bought a calendar that tells dad jokes. The punchlines are always a month late.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (or the directory set by
`MAKEFUN_OUTPUT_DIR` / `MAKEFUN_BOT_DIR`). The program is deterministic: the
joke is hard-coded, with no randomness, no network access, and no file reads at
runtime.
